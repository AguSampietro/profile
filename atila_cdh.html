Atila CDH

"Offline-first app for attendance and access control in any establishment."

Project overview

Atila CDH is an app focused on access control and attendance registration for establishments like clubs, schools and offices. It was created on November 25th, 2025.

People can enter using an access code, or by presenting passport or DNI documents. The app reads barcodes to identify the person and register each entry instantly.

How it works

  • Offline-first architecture to keep operating without internet connectivity.
  • PocketBase as backend database for user and access event management.
  • Every entry is saved and synchronized in real time when connectivity is available.
  • Built to be autonomous: only a mobile phone is needed, with no extra hardware.

Target use cases

Specially designed for clubs, schools, offices and any place that needs reliable control of people ingress and attendance records.
